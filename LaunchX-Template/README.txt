LaunchX TaskFlow Landing Page Template

Folder Structure
- index.html: Main landing page markup
- style.css: All styling, colors, and layout rules
- script.js: Interactivity (mobile menu, smooth scroll, modal, testimonials)
- assets/: Image and icon files
- README.txt: Usage instructions

Section Breakdown (Top to Bottom)
1. Header: Logo and primary navigation links
2. Hero: Main value proposition, supporting text, CTA, and hero image
3. Features / Services: Four feature cards with icons and descriptions
4. About / Why Choose Us: Trust-building copy with supporting image
5. Testimonials: Customer quotes with names and roles
6. Call to Action (CTA): Conversion-focused message and button
7. Footer: Navigation, social links, and copyright

How to Edit
Text
- Open index.html and replace the text inside headings, paragraphs, and buttons.
- Keep the section order and semantic structure intact.

Images
- Replace files inside the assets/ folder with your own images.
- Keep the filenames the same or update the src paths in index.html.
- Always provide descriptive alt text for accessibility.

Colors
- Update brand colors in style.css under the :root section.
- Primary, Secondary, Accent, and Neutral colors are defined at the top.

Minor Layout Tweaks
- Adjust spacing by editing padding and margin values in style.css.
- Use 8px increments to keep spacing consistent.
- Keep button border radius at 6px to match the brand.

What Not to Change
- Do not rename files or folders.
- Do not reorder or remove sections.
- Keep semantic HTML elements (header, nav, section, footer, ul, li, button).
- Keep JavaScript minimal and limited to the provided utilities.
